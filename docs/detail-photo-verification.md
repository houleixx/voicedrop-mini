# 音频详情图片生成与加载验证

此次仅调整小程序图片显示状态，不修改后端协议、图片 marker、文章编辑请求字段或文字生成处理。Android、HarmonyOS、iOS 无需同步修改。

- 已知图片菜单生成：0.9 秒宽限后显示制作中，失败请求间隔 3 秒重试，最多等待 5 分钟。
- 自定义/语音指令以及无法确认来源的图片：使用中性的“正在获取图片”，同样限时重试，不根据 404 宣称生成失败。
- 已上传、已显示过的图片：使用普通加载状态，失败后自动重试窗口为 15 秒。
- 下载后还需等待 image 组件加载成功；解码或渲染失败不会立即终止恢复。等待渲染的生成图片不使用懒加载，避免屏幕外图片因未触发加载而被误判失败。
- 本地按 owner scope 和文章 stem 保存图片 key、操作来源、等待期限，不保存指令正文或凭据。重进页面保留等待期限；超时后重进仍尝试下载已晚到的图片。未知来源采用中性提示。
- 重试按钮只重新读取图片，不重新提交绘图，不主动产生新的生成费用。

## 微信开发者工具与真机步骤（待执行）

1. 长按文字分别生成公众号题图、卡通解释图；图片尚不存在时应保持等待，生成后按真实比例显示。
2. 长按已显示图片分别应用卡通、广告、水彩、素描、油画、胶片；应等待新 key 出图，不能提前加载失败。
3. 使用自定义或语音指令生成任意比例图片、一次插入多张图；无法确认任务来源时使用中性文案，各图独立完成。
4. 图生成过程中继续改写正文；文字应正常更新、队列正常完成，图片等待期限不被重置。纯文字改写不能新增图片制作占位。
5. 图生成过程中退出重进、切换文章版本再返回；已知任务继续等待，不能把上一版本的图片状态错误套到另一张图。切换账号不应复用其他 owner 的提示记录。
6. 插入相册照片、打开已有照片；使用加载提示，不显示制作中。测试弱网、离线恢复、下载成功但图片无法解码，以及本地文件失效时的远程兜底。
7. 模拟持续缺图超过 5 分钟、已知旧图读取失败超过 15 秒；应显示“暂时无法显示”和重试按钮。点击重试不能产生新的文章编辑请求。
8. 保持真机合法域名检查开启，检查 CDN/源站下载；页面退出后旧请求不能覆盖新页面状态。

自动验证：`npm test`、`npm run validate:miniapp`。
