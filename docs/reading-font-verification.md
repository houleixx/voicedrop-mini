# 阅读字号验证

本轮仅实现小程序的社区与分享文章，书籍、Android、HarmonyOS 后续处理。五档倍率与 iOS 一致：0.9 / 1 / 1.15 / 1.3 / 1.5。偏好仅保存在本机，不上传、不随账户同步，也不加入分享链接。

自动验证（2026-10-12）：`npm test` 854 项通过（新增阅读字号测试 8 项）；`npm run validate:miniapp` → Miniapp static OK；`git diff --check` 通过。现有 ASR 网络诊断测试遇到 DNS ENOTFOUND 且按其既有逻辑正常结束，因此不代表本次验证了线上 ASR 联调。

微信开发者工具及 iOS/Android 微信真机补充验证：

1. 设置 → 其他 → 阅读字号选择超大；进入社区文章、分享文章，检查主标题、章节标题、Markdown 标题、列表、引用及正文变大，行高跟随文字，长英文/链接可换行。
2. 两类文章右上角 ⋯ → 字号切换全部五档，当前档带勾选，切换即时生效；取消不改变偏好。
3. 从分享文章改字号后返回已打开的社区文章，再返回设置，确认三处同步；关闭并重开小程序后仍保存。选择标准恢复原字号。
4. 确认照片尺寸、工具栏、举报/分享/投币/喜欢/回应等操作保持原样，分享内容及链接不带字号；最大档仍能纵向读完，无横向滚动。
5. 社区提示词帖不显示字号入口且正文/标题不跟随；自己的文章编辑页及行号、光标不受影响；书籍字号暂不跟随。
6. 切换 English，检查设置说明、档位名称及保存失败提示；断网仍可调整。清除缓存后保留阅读偏好。

这些视觉及微信运行时验证需在开发者工具或真机执行，Node 测试不能替代。


## 自定义字号底部弹窗

- 设置、社区文章和分享文章共用 reading-font-sheet，替换 wx.showActionSheet；书籍范围保持原约定。
- 样式参考音频「换个风格重写」：暖白圆角面板、右上角关闭按钮、底部安全区，补充滑入/滑出动画。标题居中、选项左对齐、右侧勾选，标题和选项分隔线缩进一致。
- 手动检查：三个入口打开时选中项正确，逐档切换后正文即时变化并持久化；遮罩和关闭按钮仅关闭，不改字号；弹窗内容可滚动，背景不穿透滚动；重开及切换语言后标签和选中项刷新。
- 更新已有选择、取消、存储失败、页面同步及语言测试以覆盖自定义组件；按用户要求未运行自动测试。仅进行 JavaScript 语法、小程序结构及 diff 静态检查，实际渲染留待微信开发者工具和真机验证。
